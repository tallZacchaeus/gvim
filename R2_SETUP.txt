📋 CLOUDFLARE R2 SETUP FOR RCLONE

To configure rclone, you need R2 API credentials:

1. Go to: https://dash.cloudflare.com
2. Click "R2" in the left sidebar
3. Click "Manage R2 API Tokens" (top right)
4. Click "Create API Token"
5. Give it a name: "rclone-gvim"
6. Permissions: "Object Read & Write" or "Admin Read & Write"
7. Click "Create API Token"

You'll see:
- Access Key ID
- Secret Access Key  
- Endpoint URL (looks like: https://ACCOUNT_ID.r2.cloudflarestorage.com)

Copy those values - you'll need them for the next step!

Once you have them, I'll configure rclone automatically.
